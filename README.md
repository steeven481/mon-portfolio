Portfolio professionnel développé avec React, TypeScript et Tailwind CSS. Présente mes compétences, projets et expériences en développement web.

### 🔗 **[Visiter le site → https://steevenyiemtsa.netlify.app](https://steevenyiemtsa.netlify.app)**

## 🛠 Technologies utilisées

- **Framework:** React 18 + TypeScript
- **Build Tool:** Vite
- **Styling:** Tailwind CSS + shadcn/ui
- **Icons:** Lucide React
- **Internationalisation:** react-i18next
- **Déploiement:** Netlify

## 📦 Installation et développement local

### Prérequis
- Node.js (version 18 ou supérieure)
- npm ou yarn

### Instructions d'installation

```bash
# 1. Cloner le repository
git clone https://github.com/steeven481/mon-portfolio.git

# 2. Se déplacer dans le dossier du projet
cd mon-portfolio

# 3. Installer les dépendances
npm install

# 4. Lancer le serveur de développement
npm run dev
